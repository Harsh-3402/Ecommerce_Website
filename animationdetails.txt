| Library               | Main purpose        | What we can use it for                                              |
| --------------------- | ------------------- | ------------------------------------------------------------------- |
| **Motion**            | Animations          | Page transitions, product cards, buttons, modals, scroll animations |
| **Swiper**            | Sliders/carousels   | Hero slider, product image slider, featured products                |
| **shadcn/ui**         | UI components       | Dialogs, dropdowns, tabs, tooltips, forms, sheets                   |
| **Lucide React**      | Icons               | Cart, search, user, heart, arrows, check, menu                      |
| **Sonner**            | Toast notifications | "Added to cart", "Order placed", "Login successful"                 |
| **React Hook Form**   | Forms               | Login, signup, checkout, address forms                              |
| **Zod**               | Validation          | Cleaner form validation                                             |
| **Lenis**             | Smooth scrolling    | Premium smooth page scrolling                                       |
| **GSAP**              | Advanced animation  | Complex hero/landing animations                                     |
| **React Three Fiber** | 3D                  | 3D product/hero effects — optional                                  |
| **TanStack Query**    | Server state        | Better API fetching, caching, refetching                            |
| **Zustand**           | Global state        | Cart/user/UI state if needed later                                  |
